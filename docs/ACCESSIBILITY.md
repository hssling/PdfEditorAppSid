# Accessibility in PdfEditorApp

PdfEditorApp is designed with accessibility as a core feature. Here’s how the app supports users with different needs:

## Content Descriptions
- All interactive UI elements (buttons, icons, images) include descriptive content labels for screen readers.

## Theming and Font Scaling
- Users can toggle between light and dark themes for visual comfort.
- Font sizes scale with system settings for readability.

## Navigation
- The app uses a consistent navigation drawer and large touch targets for easy access.

## Feedback
- Loading indicators and error messages are shown for long-running or failed operations.
- All dialogs and popups are accessible via screen readers.

## Best Practices
- All text uses scalable pixel units (sp).
- Color contrast meets accessibility standards.

## Suggestions
If you encounter any accessibility issues, please open an issue on GitHub or contact the maintainer.
