# Frequently Asked Questions (FAQ)

**Q: What Android versions does PdfEditorApp support?**
A: The app targets Android SDK 24 and above (Android 7.0+).

**Q: Can I edit encrypted or password-protected PDFs?**
A: Yes, you can open, set, and remove passwords for PDFs you own.

**Q: Does the app work offline?**
A: Yes, all features work entirely offline. No data is sent to external servers.

**Q: How do I report a bug or request a feature?**
A: Open an issue on the GitHub repository with details and steps to reproduce or describe your feature request.

**Q: Can I use this app for commercial purposes?**
A: Yes, but check the license file for terms and restrictions.

**Q: Is there support for advanced PDF features like form filling or OCR?**
A: Not currently, but these may be added in future releases or via third-party SDKs.
