# Screenshots

Below are example screenshots of PdfEditorApp in action. To add your own screenshots:

1. Take screenshots on your Android device or emulator.
2. Save them in the `docs/screenshots/` directory.
3. Reference them here using markdown:

```

![PDF Editing](screenshots/edit.png)
![Scan to PDF](screenshots/scan.png)
```
