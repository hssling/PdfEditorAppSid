# PdfEditorApp Usage Guide

## Opening and Viewing PDFs
- Launch the app and use the file picker to select a PDF from your device.
- Navigate pages using swipe gestures or the navigation drawer.

## Editing PDFs
- Tap the 'Edit' button to modify text, images, or annotations.
- For text: Tap on a text area to edit, change font size, or move text.
- For images: Tap to select, replace, or reposition images.
- For annotations: Add, edit, or delete highlights, notes, or drawings.

## Adding Digital Signatures
- Select the 'Signature' option in the editor.
- Draw your signature using your finger or stylus.
- Place the signature on the desired page and location.

## Batch Processing (Merge/Split)
- Use the 'Batch' menu to merge multiple PDFs or split a PDF by page range.
- Select files and specify page ranges as prompted.

## Scanning to PDF
- Tap 'Scan' to launch the camera (CameraX integration).
- Capture images and convert them directly to a new PDF document.

## Accessibility Features
- Toggle dark/light theme in the app settings.
- Adjust font size for better readability.
- All interactive elements have content descriptions for screen readers.

## Security
- Set or remove a password for any PDF via the security menu.
- All file operations provide clear feedback and error messages.

## Troubleshooting
- If a PDF fails to open or edit, ensure it is not encrypted or corrupted.
- For large PDFs, allow extra time for loading and processing.

## Support
- For issues or feature requests, open an issue on the GitHub repository.
